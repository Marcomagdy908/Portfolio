# 👨‍💻 Marco Magdy — Portfolio

**HTML · CSS · JavaScript · Bootstrap**

A personal portfolio presenting my software projects, education, technical skills, and experience.

## ✨ Feature reel

- Sections for introduction, education, skills, experience, projects, and contact.
- Project cards linking to source repositories and a task manager demo.
- Responsive Bootstrap layout and AOS scroll animations.
- Links to LinkedIn, GitHub, and my resume.

## 🚀 Run locally

Clone the repository and serve it as a static website:

```bash
git clone https://github.com/Marcomagdy908/Portfolio.git
cd Portfolio
python -m http.server 8000
```

Open **http://localhost:8000**. No npm installation or compilation is required. Bootstrap, AOS, and other CDN resources need an internet connection.

## 🗂️ Project map

| File | Purpose |
| --- | --- |
| `index.html` | Page structure and portfolio content |
| `style.css` | Custom styling and layout |
| `portfolio.js` | Browser interactions |
| `assets/` | Branding, photos, and project images |

## 📝 Customization

Update the text and project links in `index.html`, replace images in `assets/`, and adjust the theme in `style.css`.

The contact form is a frontend form; the repository does not include a service that delivers its submissions.
